# GMP 바이오공정 문제집

GMP·바이오공정 강의 복습용 **시험지형 문제집 웹 앱**입니다(5지선다 + 용어 짝짓기 + 서술형).
태블릿·PC·휴대폰 브라우저에서 바로 쓸 수 있고, 빌드 도구 없이 HTML·CSS·JavaScript만으로 만들어져 GitHub Pages에 그대로 올리면 됩니다.

## 주요 기능

### 실전 시험지 모드 (「실전 시험지」·「전범위 모의고사」)

| 기능 | 설명 |
|---|---|
| **표지 + 출제 리포트** | 시험지를 만들면 표지가 먼저 나오고, 「시험 시작」을 눌러야 문제가 보입니다. 표지에 새 문항 수, 처음 다루는 개념, 주차 배분, PART 구성, 복습 문항 수가 나옵니다. |
| **PART I → II → III** | I 용어 정의 및 개념 확인(문항당 2점) → II 개념 간 변별, 중간 난이도(3점) → III 개념 이해와 대응, 고난도(4점, 서술형 5점). PC·태블릿은 2단, 휴대폰은 1단입니다. |
| **파란 펜 답안 표시** | 보기를 누르면 번호에 파란 펜 동그라미가 쳐지고 답안지(OMR)에 바로 옮겨집니다. OMR에서 눌러도 시험지에 표시됩니다. OMR은 PC에서 오른쪽에 고정, 태블릿·휴대폰에서는 「답안지」 버튼으로 엽니다. |
| **타이머** | 100점 = 90분 비율(총점 × 0.9분). 시간이 끝나면 자동 제출됩니다. 창을 닫으면 시간이 멈추고, 처음 화면의 「이어서 풀기」로 남은 시간 그대로 이어 풉니다. |
| **빨간 펜 채점** | 맞은 문항 번호에 ○, 틀린 문항에 빗금, 정답 보기에 빨간 동그라미를 치고 점수는 손글씨체로 적습니다. 문항마다 해설(보기별 해설·PDF 출처)이 붙고, 파트별·주차별 점수와 「틀린 문제만 보기」가 있습니다. 마지막 채점지는 처음 화면의 「채점지 보기」로 다시 열 수 있습니다. |
| **서술형 자가 채점** | 제출 후 모범답안·채점 요소(핵심어)와 비교해 ○/✗를 누르면 점수와 기록에 반영됩니다. |

### 출제 알고리즘

| 규칙 | 설명 |
|---|---|
| **같은 문항 반복 금지** | 선택한 범위의 모든 문항이 한 번씩 나오기 전에는 같은 문항을 다시 내지 않습니다(복습 칸 제외). 한 바퀴를 다 돌면 두 번째 바퀴에서 아직 안 나온 문항을 다시 우선합니다. |
| **개념 고루 담기** | 처음 다루는 개념에 가점, 한 시험지 안에서 개념이 겹치면 감점합니다(예: 같은 용어의 정의→용어·용어→정의 문항은 한 시험지에 같이 나오지 않음). |
| **비율 유지** | 주차는 선택한 범위의 문항 비율대로, PART는 실전 비율(I 40 % · II 45 % · III 15 %)대로 담습니다. |
| **출제 전략** | 미출제 우선(복습 20 %) / 균형(40 %) / 약점 집중(70 %). 복습 칸은 오답 노트와 정답률 낮은 문항에서 채웁니다. |
| **출제 현황 보기** | 시작 화면에서 출제된 문항 수·다룬 개념 수·현재 몇 바퀴째인지 보고, 「출제 현황」에서 아직 안 다룬 개념 목록을 단원별로 확인합니다. |

### 그 밖의 기능

| 기능 | 설명 |
|---|---|
| **단원별 학습** | 답을 고르면 즉시 정답/오답·해설·보기별 해설·PDF 출처를 보여 줍니다. 서술형은 답을 적고 「모범답안과 비교하기」 후 ○/✗로 채점합니다. |
| **용어 정리 문항** | 강의의 용어 432개를 정의→용어, 용어→정의, 4개 용어 짝짓기 문항으로 만들었습니다(PART I). |
| **무작위 섞기** | 문제 순서(시험지는 PART 안에서)와 보기 순서를 섞습니다. 섞어도 정답 판정·보기별 해설 번호가 정확히 따라갑니다. |
| **오답 노트** | 틀린 문제(시험 모드의 미응답 포함)를 저장하고 「오답만 다시 풀기」로 복습합니다. 다시 맞히면 오답 노트에서 빠집니다. |
| **기록** | 회차별 점수, 주차(단원)별·PART별 정답률을 저장해 결과 화면과 「기록」 화면에 보여 줍니다. |
| **화면** | 한국어 UI, 모바일 우선, 큰 터치 버튼, 다크 모드(자동/라이트/다크), 인쇄용 시험지. |

기록은 **이 기기의 이 브라우저(localStorage)에만** 저장됩니다. 휴대폰과 PC의 기록은 서로 공유되지 않습니다.

## GitHub Pages 켜는 방법

1. 이 저장소의 변경 사항이 공개할 브랜치(보통 `main`)에 들어가 있는지 확인합니다.
   (작업 브랜치에만 있다면 먼저 Pull Request를 만들어 `main`에 병합하세요.)
2. GitHub 저장소 페이지에서 **Settings → Pages** 로 이동합니다.
3. **Build and deployment → Source** 를 **Deploy from a branch** 로 선택합니다.
4. **Branch** 를 `main`, 폴더를 `/ (root)` 로 고르고 **Save** 를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나타납니다.
   보통 `https://<깃허브 아이디>.github.io/<저장소 이름>/` 형태이며, 이 저장소라면
   `https://jsm012003-sketch.github.io/GMP-Quiz/` 입니다.
6. 휴대폰·태블릿에서는 그 주소를 열고 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

> 참고: 비공개(private) 저장소는 GitHub 무료 플랜에서 Pages를 켤 수 없습니다. 저장소를 공개로 바꾸거나 유료 플랜이 필요합니다.
> 문제 파일을 고친 뒤 바로 반영되지 않으면 1~2분 기다렸다가 새로고침하세요.

### 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭으로 열면(file://) 브라우저 보안 정책 때문에 문제 파일을 읽지 못합니다. 폴더에서 간단한 서버를 띄워 여세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 문제 파일 추가 방법

문제는 `questions/` 폴더의 JSON 파일에 있고, **`questions/index.json` 목록에 파일명만 적으면** 자동으로 범위 선택에 나타납니다.

1. `questions/` 폴더에 새 파일을 만듭니다. 예: `questions/wk03.json`
2. 아래 형식으로 문항을 적습니다.
3. `questions/index.json` 목록에 파일명을 추가합니다.

   ```json
   ["ot.json", "wk02.json", "…", "wk08.json", "integrated.json", "terms-ot.json", "…"]
   ```

   같은 `week`를 쓰는 파일은 한 단원으로 합쳐지며, 단원 제목은 목록에서 먼저 나온 파일의 `title`을 씁니다.

4. (권장) 형식 검사기를 실행합니다. 오류가 있으면 어떤 파일 몇 번째 문항인지 알려 줍니다.

   ```bash
   python3 tools/validate_questions.py
   ```

5. 커밋하고 푸시하면 GitHub Pages에 반영됩니다.

### 문제 JSON 형식

```json
{
  "week": "WK03",
  "title": "Upstream Process 2",
  "questions": [
    {
      "id": "wk03-001",
      "type": "상황판단",
      "question": "문제 본문",
      "box": ["ㄱ. (선택) <보기> 진술", "ㄴ. ...", "ㄷ. ..."],
      "choices": ["보기1", "보기2", "보기3", "보기4", "보기5"],
      "answer": 2,
      "explanation": "해설. **굵게** 표시 가능",
      "choiceNotes": ["보기1이 맞거나 틀린 이유", "…", "…", "…", "…"],
      "source": "WK03 Upstream Process 2 PDF p.12–14, 강의 01:32"
    },
    {
      "id": "wk03-040",
      "type": "서술형",
      "format": "essay",
      "part": 3,
      "question": "서술형 문제 본문",
      "modelAnswer": "모범답안",
      "keywords": ["채점 요소 1", "채점 요소 2"],
      "explanation": "해설",
      "source": "WK03 PDF p.20"
    }
  ]
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `week` | ✔ | 단원 이름(범위 선택·통계의 기준). 같은 `week`를 쓴 파일은 한 단원으로 합쳐집니다. |
| `title` | ✔ | 단원 제목 |
| `id` | ✔ | 전체 파일에서 겹치지 않는 고유 번호. **한 번 정한 id는 바꾸지 마세요**(기록·오답 노트가 id로 연결됩니다). |
| `type` |  | `용어` · `개념` · `연결` · `상황판단` · `서술형` (`계산`은 예전 문항 호환용) |
| `part` |  | 시험지 PART(1~3). 없으면 유형으로 정함: 용어 → I, 개념·연결 → II, 상황판단·서술형 → III |
| `format` |  | 서술형이면 `"essay"`. 이때 `choices`·`answer` 대신 `modelAnswer`(모범답안)와 `keywords`(채점 요소)를 씁니다. |
| `concepts` |  | 이 문항이 다루는 개념 이름 목록. 없으면 `tags`를 개념으로 씁니다(출제 현황·개념 중복 감점에 사용). |
| `question` | ✔ | 문제 본문 |
| `box` |  | `<보기>` 상자에 들어갈 진술 목록(「있는 대로 고른 것은?」 유형) |
| `choices` | ✔(객관식) | 보기 배열(2~10개, 기본 5지선다) |
| `answer` | ✔(객관식) | 정답 번호, **1부터 시작** |
| `explanation` |  | 해설. `**굵게**`와 줄바꿈 사용 가능. 보기를 섞으므로 ①② 같은 보기 번호는 쓰지 마세요. |
| `choiceNotes` |  | 보기별 해설(보기와 같은 순서·같은 개수). 화면에서는 섞인 번호에 맞춰 표시됩니다. |
| `source` |  | 출처. `p.`는 **PDF 뷰어의 쪽 번호**입니다(슬라이드 하단 'Page / N'과 1~2쪽 차이 날 수 있음). 강의 녹음은 `강의 mm:ss`. |

### 용어 정리 문항 만들기

용어 정리 문항(`questions/terms-*.json`)은 **직접 고치지 말고** `glossary/<단원>.json`의 용어집을 고친 뒤 생성기를 돌립니다.

```bash
python3 tools/build_terms.py        # glossary/*.json → questions/terms-*.json
python3 tools/validate_questions.py
```

용어집 항목은 `{"no": 번호, "term": "용어 (설명)", "group": "헷갈리는 묶음", "def": "정의", "src": "출처"}`이며, 오답 선지는 같은 `group`의 용어에서 먼저 고릅니다. 문항 id는 용어 번호로 정해지므로 **번호를 바꾸거나 재사용하지 마세요**(새 용어는 끝 번호 다음으로 추가).

단원별로 어떤 주제가 출제되었고 무엇이 아직 미출제인지는 [`docs/coverage.md`](docs/coverage.md)에 정리되어 있습니다.

## 강의자료·녹음본으로 문제집 업데이트하기

새 강의 PDF나 강의 녹음 텍스트를 Claude에게 올리고 "문제집 업데이트해 줘"라고 요청하면, [`CLAUDE.md`](CLAUDE.md)의 출제 규칙(시험지 형식, 5지선다, 공정 통합형 문항, 문항별 PDF 출처, 미출제 요소 반영)에 따라 새 문항 파일을 만들고 `index.json`과 `docs/coverage.md`를 함께 갱신합니다. 녹음 텍스트가 있으면 출처에 `강의 mm:ss`가 함께 붙습니다.

## 폴더 구조

```
index.html              앱 화면(진입점)
css/style.css           스타일(모바일 우선·다크 모드·인쇄용 시험지)
js/app.js               앱 로직(출제 알고리즘·시험지·채점·오답 노트·기록)
questions/index.json    불러올 문제 파일 목록
questions/*.json        단원별 문제(본문)
questions/terms-*.json  용어 정리 문항(자동 생성)
glossary/*.json         단원별 용어집(용어 정리 문항의 원본)
tools/build_terms.py    용어집 → 용어 정리 문항 생성기
tools/validate_questions.py  문제 파일 형식 검사기
docs/coverage.md        단원별 출제/미출제 현황
CLAUDE.md               출제 규칙(문제집 업데이트용)
```
